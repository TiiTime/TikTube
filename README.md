## Deutsch

TikTube ist ein kleines Windows-Fenster für YouTube Shorts und TikTok. Mit dem Mausrad geht es zum nächsten Video, nach oben zurück. YouTube bleibt die Shorts-Ansicht, TikTok die normale Seite. Es werden keine fremden Videos heruntergeladen.

## English

TikTube is a small Windows window for YouTube Shorts and TikTok. The mouse wheel moves to the next video, and up goes back. YouTube stays in the Shorts view. TikTok uses the normal site. Other people's videos are not downloaded.

[See it on the Tii site](https://tiitime.github.io/Tii/?lang=en#tiktube)
